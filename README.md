# Timeless – Backend
API REST para la tienda de ropa Timeless.
Incluye autenticación con JWT, gestión de productos con variantes por color e imágenes en Cloudinary, filtros avanzados, paginación, reordenamiento manual, clientes y registro de ventas.

Tech Stack:

Node.js + Express

MongoDB + Mongoose

Cloudinary (carga y borrado de imágenes)

JWT (login/admin protegido)

Multer (cuando aplique para uploads locales antes de Cloudinary)

CORS, Helmet, morgan (logs), etc.
